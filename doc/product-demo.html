📋 产品概述

产品定位

AI运维助手是一款面向运维工程师、技术支持和研发人员的智能运维工具。 通过自然语言交互，让AI帮你批量管理服务器、诊断问题、分析日志，把复杂的运维工作变得简单高效。

目标用户

👨‍💻

运维工程师

批量部署、日志分析、性能监控

🛠️

技术支持

快速排查问题、远程协助

🔬

研发人员

环境部署、测试环境管理

核心价值

  • 效率提升10倍 - 一句话完成批量操作，不用写脚本
  • 降低技术门槛 - 新手也能完成复杂运维任务
  • 智能诊断 - AI自动分析日志、coredump、网络包
  • 知识沉淀 - 内置知识库，AI理解你公司的业务环境
  • 安全可控 - 所有操作可审计，权限细粒度控制

📚 智能知识库

为什么需要知识库？

❌ 没有知识库

👤 用户: "帮我重启应用服务"
🤖 AI: "请问服务名称是什么？"
👤 用户: "Tomcat"
🤖 AI: "部署在哪些服务器？"
👤 用户: "Web-01到Web-03"
🤖 AI: "启动命令是？"
👤 用户: "..."

⚠️ 每次都要重复交代

✅ 有知识库

👤 用户: "帮我重启应用服务"
🤖 AI: "好的！根据知识库：
- 服务：Tomcat 9.0
- 服务器：Web-01~03
- 命令：sh /opt/tomcat/bin/startup.sh
正在执行重启..."

✓ 一句话搞定

知识库目录结构

knowledge-base/ ├── 📁 company/ # 公司级配置 │ ├── basic-info.yaml # 基本信息 │ ├── servers.yaml # 服务器清单 │ └── contacts.yaml # 联系人信息 │ ├── 📁 environments/ # 环境配置 │ ├── 📁 production/ # 生产环境 │ │ ├── servers.yaml # 服务器列表 │ │ ├── services.yaml # 服务配置 │ │ ├── ports.yaml # 端口映射 │ │ └── paths.yaml # 路径规范 │ ├── 📁 staging/ # 预发布环境 │ └── 📁 development/ # 开发环境 │ ├── 📁 services/ # 服务知识库 │ ├── 📁 web-app/ │ │ ├── service.yaml # 服务定义 │ │ ├── deployment.yaml # 部署规范 │ │ ├── troubleshooting.yaml # 故障排查 │ │ └── monitoring.yaml # 监控指标 │ ├── 📁 database/ │ └── 📁 cache/ │ ├── 📁 operations/ # 运维操作手册 │ ├── 📁 deployment/ # 部署流程 │ ├── 📁 monitoring/ # 监控 │ └── 📁 emergency/ # 应急预案 │ └── 📁 standards/ # 规范标准 ├── naming.yaml # 命名规范 ├── directory-structure.yaml # 目录结构 └── port-allocation.yaml # 端口分配

配置文件示例

公司基本信息 (company/basic-info.yaml)

company: name: "某某科技有限公司" domain: "example.com" common_directories: logs: "/opt/logs" applications: "/opt/apps" backups: "/data/backups" common_ports: http: 8080 https: 9443 admin: 8888

服务配置 (services/web-app/service.yaml)

service: name: "Web应用" type: "tomcat" deployment: servers: [Web-01, Web-02, Web-03] paths: install_dir: "/opt/apps/tomcat" logs_dir: "/opt/logs/tomcat" ports: http: 9443 commands: start: "sh /opt/apps/tomcat/bin/startup.sh" stop: "sh /opt/apps/tomcat/bin/shutdown.sh"

界面设计说明

  • 左侧面板：资源列表，支持多种资源类型（SSH服务器、Rancher、Kubernetes等），显示静态信息和实时监控数据
  • 资源信息展示：
    • SSH服务器：显示系统版本、架构、CPU/内存使用率（每10秒更新）
    • Rancher：显示集群数量和总机器数
    • Kubernetes：显示节点数和Pod运行状态
  • 右侧面板：AI对话界面，类似聊天软件的体验
  • 暗色主题：减少视觉疲劳，专业工程师风格
  • 命令输出：终端风格展示，支持语法高亮
  • 实时反馈：进度条、状态提示、错误高亮
